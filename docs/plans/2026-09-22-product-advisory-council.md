# 产品顾问团宣传页

- URL: `/product-advisory-council/`；作为第二个项目加入中文首页及其他五种语言首页。外语入口明确标注产品页为中文。
- 14 位顾问，沿用公开仓库的示意头像；每人 4 组静态示例问答，共 56 组。问题和答案源自公开方法卡，逐项保留编号，不暗示真人发言或在线生成。
- 纸色、墨色、陶土红与鼠尾草绿；桌面头像墙与问答并排，移动端上下排列。原生 details 支持键盘展开，头像深链接可直接分享，禁用 JavaScript 时所有问答仍可阅读。
- 公开来源及固定 commit 记录在 `content/products/council.json`；发布构建仅使用仓库内数据，不依赖私人资料或相邻仓库。头像来自同一公开版本。
- 接入现有生成器、sitemap 和首页；下载入口指向公开 Releases，附安装说明与可复制的使用示例。
- 验收：全站 build / validate；浏览器检查 14 人、每人 4 问、头像切换、移动端宽度、深链接及无 JavaScript 回退。

## 方法卡片页

- 56 个方法线索链接现在跳转站内 `/product-advisory-council/cards/<method-id>/`。
- 正面：小头像、顾问名字、居中方法名称。点击、Enter 或 Space 翻面；背面展示公开卡片原有的摘要、条件、问题、行动与边界。
- 每位顾问 4 张卡片支持前后浏览及返回问答；来源固定到原公开包 commit。无 JavaScript 时顺序显示两面，减少动态效果偏好下禁用翻转动画。
- 验证：build / validate 通过（187 HTML 页面，145 sitemap URL）；浏览器确认站内跳转、点击翻面、键盘翻回、390px 手机无溢出、下一张及返回、无脚本内容可读。
