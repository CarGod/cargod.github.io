概览

翻翻词卡是一款本地优先的 Chrome 扩展。开发者不运营用于接收扩展用户数据的服务器，不使用广告、分析或追踪服务，也不会出售用户数据。

不配置 AI 模型时，查词和翻译走 Google 翻译接口；配置后走用户选择的 AI 服务商。只有当用户主动划词、翻译、开启字幕或 AI 听译、选择配置同步方式或启用 GitHub 同步时，数据才会发送给第三方服务。

扩展处理的数据

  • 网页内容与浏览信息：当用户主动划词、解释或翻译时，扩展读取选中文字、附近句子或段落、页面标题和页面网址。整页或整段翻译会读取当前页面中可见的文本。
  • 翻翻模式与收藏词高亮：用户开启翻翻模式后，扩展会在本机扫描当前页面中可见的文本，并与保存在浏览器本地的词库进行匹配。匹配与高亮完全在本机完成，不会把页面内容发送给 AI 服务商、开发者或其他第三方。
  • YouTube 视频字幕：当用户在 YouTube 播放器上打开双语字幕，或已启用自动字幕时，扩展读取当前视频的字幕轨列表与字幕文本。字幕请求由页面上下文向 youtube.com 发出，因此会像页面自身的字幕请求一样携带浏览器已有的 YouTube Cookie；扩展不读取、不保存、也不传输这些 Cookie。播放器生成的一次性校验参数仅用于紧接着的一次字幕请求，不保存，也不发送给开发者或其他第三方。
  • 其他网站的视频字幕：用户打开某个视频的双语字幕、已启用自动字幕，或点选了播放器上的字幕区域后，扩展会读取该视频的字幕轨或那块区域里的文字用于翻译；点选的位置只以页面选择器的形式保存在本机。在 bilibili.com 上，扩展会在播放器自己的字幕菜单里替用户选上字幕，然后把播放器已经加载的那个字幕文件再取一份（同一地址，不带账号 Cookie）；扩展不调用 B 站的其他接口，B 站账号信息不会发往任何地方。
  • AI 听译：默认关闭，需先在视频设置中允许；仅在用户随后点击播放器的「开启 AI 听译」后读取该播放器的音轨，不使用麦克风。语音识别在浏览器本地运行，音频片段只保存在内存中，不上传、不写入词库或同步。识别文字、最近几句上下文与页面标题会直接发送给用户已配置的 AI 服务，用于纠错和翻译。关闭听译设置、停止听译、离开页面或切换视频会释放音频与本地模型会话。
  • 输入框翻译（三击空格）：扩展会监听网页输入框里的按键，只用来判断是否连续按了三次空格；触发后把该输入框里已有的文字发给用户选择的 AI 服务商翻译并原位替换。不记录、不保存输入内容。
  • 翻译故障恢复：只有用户选择临时服务后，后续翻译才会在后台向原模型发送固定短文本（不包含页面内容）检查恢复情况。并发检查合并，单次最长 20 秒；恢复后仅提示，由用户决定是否切回。故障状态与临时服务选择仅保存在本机，不复制密钥、不写入配置同步。临时使用 Google 时，翻译文本直接发往 Google，听译保留本地识别但不进行 AI 纠错。
  • 学习数据：收藏的词、解释、来源句子与网址、复习记录、学习活动和用户设置。
  • 身份验证信息：用户自行填写的 AI 服务 API Key，以及启用 GitHub 同步时填写的 GitHub Token。

词卡、复习记录和学习活动保存在用户自己的浏览器 chrome.storage.local 中。首次设置先由用户选择配置目录；授权后，设置、AI API Key 和 GitHub Token 会保存到该目录的配置文件。用户也可选择仅本机配置，或主动启用浏览器账号同步，启用后才将这些配置写入浏览器管理的 chrome.storage.sync，随用户的浏览器账号在其设备间同步；浏览器不支持同步时仅保存在本机。已有安装保留原先选择的配置方式。用户可在「配置同步」里切换为仅本机。

扩展每次升级前会在本机 chrome.storage.local 中保留升级前的设置副本（最多 3 份，含 AI API Key 和 GitHub Token），仅用于升级后在设置页恢复丢失的配置；副本不写入配置文件或浏览器同步，不随配置导出，也不发送到任何地方。开发者无法访问这些本地数据或用户的浏览器同步空间。

数据何时会发送给第三方

扩展提供以下传输方式（自定义本机开发地址除外，网络请求使用 HTTPS）：

  1. 未配置 AI 模型时（安装后的默认状态），选中文字、所在句子、被翻译的段落和字幕文本会直接发送给 Google 翻译接口（translate.googleapis.com）用于翻译，不经中转；Google 如何处理这些数据由 Google 的隐私政策约束。
  2. 用户选择并配置 AI 模型后，选中文字、必要上下文、页面标题和网址会直接发送给用户选择的服务商（Anthropic、OpenAI、DeepSeek、Google Gemini，或用户填写的兼容 API 地址），用于生成解释或翻译。AI 请求中的 API Key 发送给对应服务商；配置备份中的密钥传输见第 4、5 项。用户打开视频双语字幕（YouTube 或其他网站）后，当前视频的字幕文本与页面标题会以同样方式发送给该服务商，用于生成译文。用户在输入框连按三次空格触发翻译时，该输入框里已有的文字也会以同样方式发送给该服务商。
  3. 用户主动启用 GitHub 同步后，词卡、来源信息、复习记录和学习活动会发送到用户自己的 GitHub 仓库；GitHub 请求中的 Token 发送给 GitHub API。配置恢复不会把设置或密钥提交到词卡仓库。
  4. 用户选择浏览器账号自动配置同步后，插件设置、AI API Key 和 GitHub Token 会写入浏览器的同步空间。是否跨设备传输由浏览器登录状态与同步设置决定，由 Google、Microsoft 或相应浏览器服务提供商处理。扩展不增加独立口令，不提供应用层额外加密，且无法确认云端上传完成时间。
  5. 用户可导出包含完整密钥的 JSON 配置文件，或授权插件读写所选目录中的 FanFan Cards/config.json。选择 iCloud Drive 目录时，Apple 系统服务负责后续同步，扩展只操作用户授权的本地文件。目录句柄仅保存在本机；新设备需重新选择目录，权限失效时需重新授权。

AI 听译首次使用会从 Hugging Face 下载固定版本的语音模型数据，并缓存到浏览器中；后续可复用缓存。模型下载服务不会收到音频、转写文字或 AI 密钥，只会收到下载请求及通常的网络连接信息。推理程序与 WebAssembly 随扩展打包，不下载执行远程代码。模型缓存可通过移除扩展数据或卸载扩展清除。

开发者不会通过中转服务器接收上述数据。第三方如何处理数据，由用户与该服务商之间的条款和隐私政策约束。

数据保留与删除

本地数据会一直保留，直到用户在扩展中清空数据、移除扩展数据或卸载扩展。用户可以在设置页导出插件配置 JSON（包含密钥，不包含词卡与复习记录），也可以清空缓存或全部词卡。词卡与复习记录通过用户自己的 GitHub 仓库同步恢复。

同步到 GitHub 的数据由用户自己的 GitHub 仓库设置与操作决定，用户可在 GitHub 中删除。配置文件由用户在所选目录中管理和删除；浏览器同步副本由浏览器账号与同步设置管理。切换为本机模式会停止本设备继续同步，不会删除其他设备或云端已有副本。

安全与最小权限

扩展不加载或执行远程代码。外部请求使用 HTTPS；仅本机开发地址允许 http://localhost。自定义 API 地址的访问权限只在用户点击“测试连接”时按目标域名申请。

扩展会在 youtube.com 上注入一段运行在页面上下文中的脚本。它只用于读取播放器公开的视频与字幕轨信息、记录上述一次性校验参数，以及代为发出获取字幕的同源请求。该脚本不访问任何扩展 API，不读取页面上的其他数据，也不与开发者的任何服务器通信。

扩展对信息的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
