How it works

从“卡住”到“记住”，只有一条路径。

01 · 在语境里解释

选中单词、短语或句子，AI 先判断它在当前上下文里的具体含义，再给基础释义、英文释义和例句。

02 · 连同来源一起收藏

每张词卡保留原句、页面、时间和模型来源。下次复习时，你看到的不只是一个孤立的中文意思。

03 · 按熟悉度再次出现

四级自评驱动间隔复习；学习面板把收藏、待复习、连续学习和熟悉度分布真实呈现出来。

04 · 数据始终属于你

默认只存在本机，可导出 JSON / CSV；你也可以主动同步到自己账号下的 GitHub 私有仓库。
